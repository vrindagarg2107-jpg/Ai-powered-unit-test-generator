# Milestone 2 handoff checklist

- [ ] Run the application locally and capture screenshots.
- [ ] Configure Gemini API key and demonstrate a successful real AI request, or clearly disclose demo mode.
- [ ] Test at least 10 distinct inputs; record actual outputs and Pass/Fail.
- [ ] Save at least 3 prompt versions and document actual changes, reasons, and observations.
- [ ] Confirm the Team ID and member details against the official Milestone 1 record.
- [ ] Record only modules that work in the submitted build.
- [ ] Record actual individual contributions and obtain agreement from all team members.
- [ ] Create a public-accessible repository/Drive folder and demo video link.
- [ ] Do not submit placeholder URLs or invented test outcomes.
